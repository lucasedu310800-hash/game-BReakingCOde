# Cenas espontâneas entre os NPCs da sede (lidas por HubLife / SocialScript).
#
# === id_da_cena                  começa uma cena
# elenco: A=Rafa B=Theo|Caio C=*  quem pode ser cada papel: nome, nomes separados por |,
#                                 um temperamento (extro, timido, preguica, nervoso, mal,
#                                 arrog, calmo) ou * (qualquer um); !Nome exclui (*|!Hank)
# relacao: A B rival|inimigo      (opcional) a relação entre A e B precisa ser uma destas:
#                                 amigo, rival, desconfia, respeito, inimigo, neutro
# precisa: cafeteira              (opcional) só acontece se isso aconteceu há pouco
#                                 (cafeteira, cochilo, bronca, pizza, elogio, briga, risada,
#                                 entrega, barulho, favor)
# interrompe: B                   (opcional) B pode estar trabalhando: para e volta depois
# peso: 2                         (opcional) chance maior de ser escolhida
#
# Falas:  A>B humor gesto | texto
#   humor: neutro sorrindo rindo surpreso confuso irritado pensativo serio satisfeito
#          desconfiado nervoso timido cansado entediado
#   gesto: - explicar discutir ombros aponta rir bracos quadril cocar facepalm nervoso
#          espreguicar aceno sim nao
#   [amigo] [rival] [desconfia] [respeito] [inimigo] [neutro] [outro] antes do humor:
#          variações seguidas da mesma fala; vale a que bater com a relação de quem fala
#          com quem ouve ([outro] = nenhuma das anteriores)
#   ! antes do | : interrompe a fala anterior antes de ela terminar
#   {A} {B} {C}: o primeiro nome de quem faz o papel
# Ações:  @ A chega | sai | cumprimenta B | entrega B item | aponta B/lugar | rir |
#         levanta B | chama B | olha B/lugar | senta
#         (lugares: cafeteira, mesa, bancada, planta, porta, quadro)
# Pausa:  ~ 1.5
